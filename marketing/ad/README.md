# Afterchart TikTok ad

25 s, 1080×1920, 60 fps, H.264 + AAC (−14 LUFS). Every visual and sound is generated by these files.
No stock footage or sound libraries are used.

| File | Purpose |
| --- | --- |
| `timeline.js` | Single source of timing: scenes, sound cues, neon flicker pattern |
| `ad.html` | The animated scene (3D phone, captions, pop-out cards, wind streaks, neon end card) |
| `render.js` | Renders `ad.html` frame by frame into ffmpeg |
| `sfx.py` | Synthesizes all sound effects + the 128 bpm music bed, synced to `timeline.js` |
| `capture.js`, `geom.js` | Capture the real app screens (demo data) into `shots/` and record element positions |

## Rebuild

```bash
node timeline.js > build/cues.json
python3 sfx.py                       # -> build/audio.wav  (needs numpy, scipy)
node render.js video 60              # -> build/video_silent.mp4  (~14 min)
ffmpeg -i build/video_silent.mp4 -i build/audio.wav -map 0:v -map 1:a -c:v copy \
  -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 320k -movflags +faststart out/afterchart_tiktok_ad.mp4
```

Preview single frames with `node render.js stills 3.4,9.9,21.5` (written to `build/`).
The screens in `shots/` show fictional demo traders, not real users.
